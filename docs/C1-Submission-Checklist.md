# SIT313 C1 — Submission Checklist

## Before recording
- [ ] Run `npm install` and `npm run dev`.
- [ ] Confirm the existing home, login, and registration routes still open.
- [ ] Open **Post** from the navigation.
- [ ] Switch between **Question** and **Article** and explain that React state causes the conditional rendering.
- [ ] Press Post with empty fields and show the validation error popup.
- [ ] Fill in valid title, content, and 1–5 comma-separated tags, then show the success popup.
- [ ] Test Clear form and a narrow/mobile browser width.
- [ ] Check that `node_modules/` is not included in the repository.
